# AnnotaMD v2.22.1

## 修复

- **复制加粗等行内格式不再丢标记**：复制加粗、斜体、删除线、行内代码或行内公式时，粘贴结果保留完整的成对标记。此前只带开头两个 `*`、结尾标记在选区之外，粘贴后变成字面星号。
- **`路径:行号` 形式的链接可以打开了**：文档中引用源码位置的链接（如 `run_agent.py:11395`）点击后打开对应文件。此前整串被当成文件名，目标不存在又没有任何提示，看起来像链接坏了。
- **链接打不开时会给出提示**：目标不存在或系统无法打开时显示通知，不再毫无反馈。

## 升级与安装

- 现有文档、评论、布局偏好与历史对话全部保留。
- macOS 提供 Apple Silicon（arm64）和 Intel（x64）的 DMG；应用内更新使用对应架构的完整 ZIP。
- Windows 提供 x64、arm64 安装包；Linux 提供安装包及便携格式。
