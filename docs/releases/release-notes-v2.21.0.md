# AnnotaMD v2.21.0

## 新增

- **内置 Pi Agent**：在设置中配置模型服务商即可使用，无需另装 Pi 或 Node.js。侧栏助手可读取当前文档全文、评论和线程回复，支持多轮讨论、文档修改、工具执行过程、请求批准，以及修改差异的保留或回退。
- **选区询问 AI**：选中文字后就地输入问题或改写要求，独立使用该选区、前后文和位置作为上下文，结果显示在浮层中。需要继续讨论时，可显式将选区引用加入侧栏 Agent 草稿。
- **多图同行与大图预览**：支持两张、三张及更多图片并排显示，同排图片协调调整尺寸，可拖动重新排列，并在浮层中放大查看。
- **评论快捷导航**：评论栏底部可直接跳到第一条评论；新建 Agent 对话提供处理或回答当前文档全部评论的建议。

## 改进

- 优化设置、Agent 对话和评论线程的布局，减少重复卡片与留白，长评论阅读和回复更紧凑。
- 获取服务商模型列表后，可勾选需要的模型再添加；模型菜单立即展开，能力信息后台加载并复用缓存。
- 侧栏读取文档与评论由内置 Agent 在应用内部完成；日常使用无需配置 AnnotaMD MCP，外部 Agent 的评论接入仍可选用。
- 精简块菜单与章节菜单中的复制操作，移除设置搜索框，减少重复入口。

## 修复

- 修复部分服务商品牌图标和代码语言图标显示不正确的问题。
- 修复模型选项点击无反应、重复默认项，以及思考强度未随模型能力正确显示的问题。
- 修复图片缩放拖动容易中断、选择同行图片时整体尺寸跳变的问题。
- 修复折叠和展开章节时，前一张表格的吸顶列名消失的问题。
- 收紧文档资源和桌面操作的访问范围，防止未授权页面或路径访问本地文件。

## 升级与安装

- 现有 Markdown 文档、评论和历史对话保留。首次使用内置 Agent，请在「设置 → Agent」添加服务商、填写密钥并启用模型。
- macOS 提供 Apple Silicon（arm64）和 Intel（x64）的 DMG；应用内更新使用对应架构的完整 ZIP。
- Windows 提供 x64、arm64 安装包；Linux 提供安装包及便携格式。
