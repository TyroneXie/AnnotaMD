# AnnotaMD v2.15.0

本版本继续打磨编辑与批注协作：图片拥有更直接的操作工具栏，批注线程会始终跟随最新消息，Mermaid、Vega 和 Sequence 新建后可以立即同时看到代码与图表；文件树、图表区域、删除线和批注下划线也更加紧凑、稳定且对齐。

## 新增

### 图片操作工具栏

- 选中图片后可直接调整行内、居左、居中或居右布局，并能清楚看到当前状态。
- 图片工具栏支持键盘操作和 Escape 关闭；打开时会自动收起文字格式工具栏，避免两个浮层重叠。

### Claude Code 权限模式

- 在“设置 → Agent”中可为 Claude Code CLI 选择“标准权限”或“完全授权”。
- 标准权限保留 Claude Code 的权限检查；完全授权适合批注栏中的非交互处理，并在界面中明确提示适用范围和风险。

### 从最新消息继续咨询

- 最新一条尚未发送的 Local 消息可直接“咨询”当前 Agent，不会在评论线程中重复生成同一条消息。
- 每条 Local 消息的编辑、删除和咨询入口统一收进右上角菜单，Agent 消息继续保持只读。

## 改进

### 批注与 Agent 对话

- 评论线程中只要新增一条 Local 或 Agent 消息，就会自动滚动到最底部，不再需要手动寻找最新回复。
- 回复框随输入增长时会保持在可见区域；长线程、Agent 处理中和消息追加后的布局更加稳定。
- 操作文案统一为“回复”和“咨询”，Agent 后台健康检查期间保持已确认状态，仅用轻量动效提示检查完成。
- 已开始输入的批注草稿会锁定原选区，不会因随后划选其他文字而改变引用范围。

### 图表编辑

- 新建 Mermaid、Vega 和 Sequence 图表时默认展示“代码和图表”，便于立即开始编写；重新打开已有文档时仍默认只展示图表。
- 空图表拥有更大的可用编辑区域，视图菜单可以正常越过图表边界，不再被短容器裁切。
- 修复快速插入过程中原段落已被替换或移除时的异常，避免 Mermaid 等图表触发渲染进程错误。

### 编辑器与导航

- 项目文件树改为接近 VS Code 的紧凑行距，同一屏可以看到更多文件和目录。
- 点击正文标题或其下方内容时，目录会同步当前章节。
- 批注下划线和删除线按每个可视行绘制为连续直线，在普通文字、行内代码及自动换行之间保持同一高度。

## 修复

- 修复居中图片的工具栏偶尔跳到窗口左上角，以及图片工具栏与文字格式工具栏同时显示的问题。
- 修复图片布局按钮状态滞后、行内图片无法便捷恢复为居中块图片的问题。
- 修复短图表区域遮挡视图下拉菜单、空图表可操作空间不足的问题。
- 修复批注新增消息后仍停留在线程中部，以及跨越不同字体和行内代码时下划线或删除线出现台阶的问题。

## macOS 安装提示

当前发行构建使用免费 ad-hoc 签名，暂未使用 Apple Developer ID 签名和公证。将 AnnotaMD 拖入“应用程序”后，如 macOS 阻止启动，可执行：

```bash
xattr -cr /Applications/AnnotaMD.app
```

也可以在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 下载校验

所有安装包均记录在 Release 的 `SHA256SUMS.txt` 中，可在下载目录执行：

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
```
