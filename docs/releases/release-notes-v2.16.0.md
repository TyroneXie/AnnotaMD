# AnnotaMD v2.16.0

本版本新增完整的右侧 Agent 工作区。你可以直接复用本机已经安装的 Codex、Claude Code、OpenCode、Cursor、CodeBuddy、Qoder、Grok 或 Pi CLI，在文档旁边持续对话、选择模型与思考强度、添加附件，并让 CLI 使用原生文件、命令、网络、Skills 和扩展能力完成任务。AnnotaMD 负责当前文档与选区上下文、审批交互、文档变更同步、Diff 审阅和整轮回退。

## 新增

### 多 CLI Agent 工作区

- Comments 与 Agent 共用同一宽度的右侧区域，可从顶部图标快速切换，切换时不会丢失会话或中断后台任务。
- 支持 Codex CLI、Claude Code CLI、OpenCode CLI、Cursor CLI、CodeBuddy Code、Qoder CLI、Grok CLI 和 Pi Coding Agent。
- 可检测本机 CLI、填写自定义可执行文件路径、测试安装与认证状态，并读取 Provider 实际提供的模型和思考强度。
- 支持流式回复、Markdown、代码块、工具状态、停止、失败重试、复制消息和放大侧栏。

### 会话、上下文与附件

- 支持新建、搜索、切换、重命名和删除历史会话；简介中同时显示更新时间和 Agent 名称，当前会话以绿色圆点标识。
- 新会话会随机展示 2-3 个常用文档任务，点击后直接填入输入框，不会立即发送。
- Agent 可接收当前文档、未保存正文和选区上下文，也可添加图片及文本文件。
- 在批注栏点击“咨询”时，始终使用 Agent 栏当前选择的 CLI、模型、思考强度和权限模式。

### 权限审批与文档审阅

- “请求批准”模式保留 CLI 自己的风险判断。CLI 发起审批时，AnnotaMD 会在对话中展示请求并把用户决定传回同一个 CLI 会话。
- “完全访问”模式允许 CLI 使用其原生文件、命令、网络、Skills、扩展和 MCP 能力，不再逐项询问。
- 每轮任务会收集 Markdown 变更并生成 Diff，可选择保留或整轮回退；文件已经再次变化时会阻止不安全的回退。
- 新建 Markdown 文档后可自动发现并打开；当前文档由 CLI 写盘后会同步回 Muya 编辑器。

### Skills 与 MCP 配置教程

- Agent 设置页提供 AnnotaMD MCP 和批注 Skill 的手动配置步骤。
- 配置内容支持一键复制，便于粘贴到 Claude Code Desktop 等外部 Agent 应用。
- 教程只提供配置内容，不会自动扫描或修改外部应用。

### 图片操作

- 图片工具栏和图片块菜单新增“复制图片”，支持本地文件、远程图片和 Data URL。
- 右键图片可直接复制或下载，菜单使用统一图标和本地化文案。

## 改进

### 更紧凑的 Agent 界面

- Agent 设置页改为更紧凑的有边框布局，测试、编辑、删除和状态结果不再撑大配置卡片。
- 用户消息靠右并使用低饱和浅绿色，Agent 回复靠左并使用中性浅灰；移除“你”和“AI”独占的标题行。
- 模型、思考强度、权限模式和 CLI 选择菜单保持打开，直到用户完成当前配置。
- Comments 与 Agent 的宽度、顶部栏高度、关闭按钮和切换状态保持一致。

### 编辑器稳定性

- 文字格式工具栏在左右边缘会自动回到编辑区域内，不再溢出或被裁切。
- 图片缩放任务会在图片移除或控件销毁时及时停止，避免残留监听和空引用错误。
- 批注下划线在粗体、行内代码、链接和自动换行之间保持连续。
- 图表复制和图片上下文菜单在真实创建、缩放和删除流程中更加稳定。

## 修复

- 修复当前历史会话圆点仍显示为灰色的问题。
- 修复选择模型后配置卡片提前关闭、思考强度无法继续选择的问题。
- 修复权限模式菜单点击后闪退或无法保持打开的问题。
- 修复 Comments 与 Agent 侧栏切换时宽度不一致、正文换行位置变化的问题。
- 修复图片删除后仍有排队中的缩放任务访问失效节点的问题。

## macOS 安装提示

当前发行构建使用免费 ad-hoc 签名，暂未使用 Apple Developer ID 签名和公证。将 AnnotaMD 拖入“应用程序”后，如 macOS 阻止启动，可执行：

```bash
xattr -cr /Applications/AnnotaMD.app
```

也可以在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 下载校验

所有安装包均记录在 Release 的 `SHA256SUMS.txt` 中，可在下载目录执行：

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
```
