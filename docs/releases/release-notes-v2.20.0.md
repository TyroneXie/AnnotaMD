# AnnotaMD v2.20.0

## 新增

- macOS 支持应用内更新：点击更新后在应用内下载并显示进度，下载完成后点击“重启更新”，即可安装并重新打开。
- 更新重启后恢复未保存的文档内容；新版本启动失败时回退到更新前的应用。

## 改进

- macOS 发现新版时只提示，下载和安装分别由两次点击触发。设置页不再显示“自动下载更新”选项。
- 侧栏更新图标显示下载进度环，便于查看下载状态。

## 修复

- 修复 macOS 临时签名版本每次点击更新都会跳转到 GitHub、无法直接更新的问题。在可写的应用安装目录中，无需付费 Apple 开发者证书即可使用应用内更新。

## 升级提示

- 从旧版升级到 v2.20.0 仍需下载安装一次；安装本版后，后续版本即可使用上述应用内更新流程。
- 建议将应用放入“应用程序”目录后运行；安装目录不可写或从临时隔离位置运行时，仍需通过下载页面手动安装。
