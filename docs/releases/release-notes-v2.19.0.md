# AnnotaMD v2.19.0

## 新增

- 双击段落、标题、列表、引用、代码块、图片和表格之间的空白，或文档首尾的空白，即可新增编辑行并显示光标，继续输入文字或添加图片。相邻已有空行时会直接进入该行。
- 表格单元格内，双击图片下方的空白即可继续编辑，方便插入第二张图片。

## 改进

- 表格单元格内按 Enter 或 Shift+Enter 可直接换行；按 Cmd+Enter（macOS）或 Ctrl+Enter（Windows/Linux）可新增整行表格。

## 修复

- 修复表格换行后光标消失，无法直观看到输入位置的问题。
- 修复删除单元格换行时残留部分 HTML 标记的问题，保留换行两侧的文字。
- 修复粘贴截图时将大段 base64 图片写入 Markdown、导致文档体积异常增大的问题；图片会按所选策略保存，正文保留图片引用。

已有的内嵌图片不会因升级自动移动或改写。
