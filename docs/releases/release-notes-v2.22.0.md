# AnnotaMD v2.22.0

## 新增

- **界面布局可选**：在「设置 → 外观 → 样式」中切换「胶囊」与「经典」。胶囊保留浮动卡片式工作区，经典恢复贴边传统布局；布局与配色主题互相独立，可随时切换。
- **选区浮层可拖动**：选中文字后弹出的问答浮层可以按住顶部引文区域拖到任意位置；浮层内的模型回复按 Markdown 渲染，代码块、列表和表格都能正常显示。

## 改进

- **窗口顶部更紧凑**：标题栏变窄，文件路径在整条顶部区域垂直居中；文档标签改为扁平标签，评论按钮并入标签行右侧，各平台一致。
- **设置页重新排版**：分组更清晰，行间用细分隔线，去掉重复的分组标题。
- **左右面板共用宽度**：Agent、搜索、大纲和评论面板共享同一侧栏宽度并有 320px 下限，切换面板不再改变侧栏宽度；侧栏较窄时 Agent 面板自动改为堆叠布局，隐藏权限按钮文字，保证内容不挤压。
- **Agent 思考过程不再撑长对话**：较长的思考内容在固定高度的框内滚动，正文和时间线保持紧凑。

## 修复

- 中间步骤的工具调用失败不再把整轮 Agent 对话标记为「失败」：只有一轮结束却没有结果时才显示失败，且失败的分组默认折叠。
- 侧栏与批注栏之间的拖拽线现在位于两个卡片间隙正中，可直接拖动，不再需要把指针移进编辑器而误触发段落悬浮菜单。
- 修复设置页中一条本应不可见的近白色分隔线，并修正标题栏文件路径偏高的问题。
- 在系统钥匙串不可用的环境中（开发构建，或以 ANNOTAMD_LOCAL_SECRETS 环境变量启动的打包版本），仍可正常保存模型服务商密钥。

## 升级与安装

- 现有文档、评论、布局偏好与历史对话保留；首次切换到新的布局后，可在同一位置随时切回经典布局。
- macOS 提供 Apple Silicon（arm64）和 Intel（x64）的 DMG；应用内更新使用对应架构的完整 ZIP。
- Windows 提供 x64、arm64 安装包；Linux 提供安装包及便携格式。
