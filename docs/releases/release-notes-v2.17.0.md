# AnnotaMD v2.17.0

本版本重新整理了 Agent 的位置、会话归组和执行时间线。Agent 现在位于左侧活动栏，与目录、搜索和大纲并列；批注栏回归纯粹的文档审阅用途。划选正文后可以直接打开 Agent，并携带当前选区继续提问。

## 新增

### 左侧 Agent 工作区

- Agent 入口移动到左侧活动栏，与目录、搜索和大纲使用一致的切换方式，再次点击当前入口即可关闭侧栏。
- 正文选区工具栏新增 Agent 按钮，可直接打开 Agent 并携带被选文字，不必先创建批注。
- 设置中新增 Agent 文字大小调节，默认字号进一步缩小，长回答可以显示更多内容。

### 项目化 CLI 会话

- AnnotaMD 发起的 Codex、Claude Code、OpenCode 等原生 CLI 会话默认归入专用的 AnnotaMD Agent 工作区，不再散落为一批无项目对话。
- CLI 仍可访问当前文档所在目录；固定工作区只负责稳定项目身份，不会限制实际文档上下文。
- 新会话标题优先采用用户问题的第一句，不再显示注入给 CLI 的英文环境说明。

## 改进

### 按真实顺序呈现执行过程

- Agent 的说明文字、思考摘要、工具调用和最终回答按实际时间线排列，不再把整轮文字拼成一个消息。
- 连续工具调用合并为一个执行过程；运行中自动展开，完成后默认折叠为一行，可按需查看完整过程。
- 展开后的说明和工具直接展示并保持层级缩进，不再出现“引用里再套折叠”的重复结构。
- 最终回答独立显示；如果 CLI 没有生成最终回答，会明确提示，不再把开场计划误认为结论。
- 状态行补充步骤数、耗时、成功、停止或失败信息，并修正图标与文字基线。

### 更专注的批注与编辑工具

- 批注栏移除“咨询 Agent”和 Agent 就绪状态，避免与独立 Agent 工作区重复。
- 文字格式工具栏恢复悬浮提示，并统一按钮尺寸、边界定位和弹出行为。
- 批注入口回到正文区域的批注标题旁，评论、Agent 和文字格式入口更易区分。

## 修复

- 修复 Agent 运行没有稳定绑定当前打开文档，或文档仅存在表格对齐、空行等序列化差异时误报 `candidate-not-canonical` 的问题。
- 修复发送前编辑器内存正文与磁盘原文短暂不一致导致 checkpoint 失败的问题；CLI 真正写盘后才进入候选内容规范化和应用流程。
- 修复工具调用和思考过程消失、执行过程层级混乱、中间输出无法折叠及最终回答识别错误的问题。
- 修复文字类型转换按钮在编辑区边缘点击无响应，以及浮层越界或被裁切的问题。

## macOS 安装提示

当前发行构建使用免费 ad-hoc 签名，暂未使用 Apple Developer ID 签名和公证。将 AnnotaMD 拖入“应用程序”后，如 macOS 阻止启动，可执行：

```bash
xattr -cr /Applications/AnnotaMD.app
```

也可以在“系统设置 → 隐私与安全性”中选择“仍要打开”。

## 下载校验

所有安装包均记录在 Release 的 `SHA256SUMS.txt` 中，可在下载目录执行：

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
```
