# AnnotaMD v2.18.0

## 新增

- 在“设置 → 外观 → 文本编辑器”中新增“左右留白（每侧）”，默认 56px。调整后自动保存，正文会随窗口宽度伸缩。

## 调整

- 移除“复制段落”的菜单、命令和快捷键入口，保留“复制 Markdown”和“复制纯文本”，减少误操作。
- 左侧块操作按钮统一保持紧凑高度，并锚定正文、标题、列表项或表格可见边框的上沿，避免上下错位或按钮过高。
- 原来的固定正文宽度控件改为左右留白控件；升级后正文自动使用窗口中可用的宽度。

## 修复

- 修复调整过列宽后增删列，后续文本列异常变窄、表格行高暴涨的问题。增删列时按现有内容重新自动排版。

## macOS 安装提示

当前 macOS 安装包使用 ad-hoc 签名。拖入“应用程序”后，如系统阻止启动，可在“系统设置 → 隐私与安全性”中选择“仍要打开”，或执行：

```bash
xattr -cr /Applications/AnnotaMD.app
```

## 下载校验

安装包校验值见 Release 中的 `SHA256SUMS.txt`，可在下载目录执行：

```bash
sha256sum -c SHA256SUMS.txt --ignore-missing
```
